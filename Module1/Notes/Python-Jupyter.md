# Python and Jupyter

## Learning objectives

- Identify users of Python
- Describe the benefits of using Python
- Describe diversity and inclusion efforts in the Python community

## About Python

- Python is widely used in data science.
- Its syntax is clear and readable.
- It is a general-purpose language with a large standard library.

## Where Python is used?

- Data science
- Artificial intelligence (AI) and machine learning (ML)
- Web development
- Internet of Things (IoT), including Raspberry Pi projects

## About Jupyter

 - Enables creation and sharing of documents containing equations, live coding, visualizations, and narrative text.

## Why Jupter?
 - Popularity
 - Ease of use, regardless of your expertise
 - Interactive interface

## Key Features of Jupyter:
 - Write and Execute code interactively
 - Support various programming language through its kernel system.
 - Reach media integration, allowing users to generate interactive plots, charts, images, videos, and more directly within the document.
 - Integrates with popular libraries and framework used in Data Science.
