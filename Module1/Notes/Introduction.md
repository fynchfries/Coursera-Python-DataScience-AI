# Course Introduction

## About Python

Python is:

- Easy to learn
- Powerful
- Supported by a large ecosystem of libraries

## Where Python is used

Python is useful for many kinds of work, including:

- Data analysis
- Web scraping
- Big data
- Finance
- Computer vision
- Natural language processing (NLP)
- Machine learning (ML)
- Deep learning (DL)
